### AI Memory Feature Overview

AI Memory allows the human agent to see notes in the **Customer Journey** module on the Agent Desktop from previous interactions with this caller. Those notes help the agent provide a better customer experience without asking the customer to repeat context that was already shared.

## Story

Customers share preferences, constraints, and past issues on every call, but that context is often discarded when the conversation ends. The next time they call, the agent starts from zero and the customer has to repeat the same details.

**Webex AI Memory** keeps that understanding and shows it in the **Customer Journey** module so the agent can personalize the next interaction.

## Call Flow Overview

1. A new call enters the voice flow and is transferred to a human agent.
2. The agent opens the **Customer Journey** module on the Agent Desktop.
3. If previous interactions exist for this caller, AI Memory shows notes and details from those interactions.
4. If no notes are shown yet, the agent continues a longer conversation so AI Memory can capture context, then a second call is used to review the Customer Journey details.
