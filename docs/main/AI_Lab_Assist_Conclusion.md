In this lab, you explored **Webex AI Assistant** features that help human agents deliver a better customer experience during and after the interaction.

### Generated Summaries

- Reviewed **AI Agent Transfer Summary** so the live agent receives context from the conversation with the AI Agent.
- Configured a **custom Wrap-up Summary** template and assigned it to your queue.

### Real-Time Assist

- Created an AI Assistant skill with a **Knowledge Base**.
- Assigned the skill to your queue so the agent can use **Get Suggestion** during a live call.
- Reviewed the preconfigured **Start Media Stream** setting that Real-Time Assist requires.

### AI Memory

- Opened the **Customer Journey** module on the Agent Desktop.
- Reviewed notes from previous interactions with the same caller so the agent does not need to ask the customer to repeat context.

---

These AI Assistant features work together across the agent experience: summaries at transfer and wrap-up, real-time guidance during the call, and memory of prior conversations for the next interaction.
